# MadDogWarner auth.md

MadDogWarner is a public cyber security blog and project site.

## Authentication

No authentication is required to read public site content, follow public links, or subscribe to the RSS feed.

This site does not currently provide agent registration, OAuth delegation, API keys, access tokens, or an `/agent/auth` endpoint.

## Public Resources

- Website: https://maddogwarner.com/
- Blog: https://maddogwarner.com/blog/
- RSS feed: https://maddogwarner.com/rss.xml
- Contact page: https://maddogwarner.com/contact/

## Contact and Community Links

Use the contact page for general enquiries. Do not submit credentials, secrets, health information, or other sensitive data.

Public community and profile links are available from the contact page and site footer.

## Agent Guidance

Agents may:

- read public pages
- subscribe to the RSS feed
- follow public profile and community links
- summarise public blog posts with attribution

Agents must not:

- attempt to bypass Cloudflare Turnstile or form protections
- submit automated contact form messages without clear user intent
- include secrets, credentials, personal health information, or regulated data in messages
- treat public links as authenticated support channels
